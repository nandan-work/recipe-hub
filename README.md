# Recipe Hub prototype

Standalone Recipe Hub UI prototype, hosted with GitHub Pages. No Claude account is required.

The prototype uses sample data. Search rankings, totals and several actions are simulated; it does not connect to production services. Changes last only for the current browser session. This snapshot may differ from later edits to the original artifact.

`prototype.html` preserves the exported page and its bundled scripts, fonts and license notices. `index.html` adds a prototype notice and download link.

Serve this directory over HTTP to preview it. GitHub Pages publishes the root of `main`; `.nojekyll` disables Jekyll processing.
